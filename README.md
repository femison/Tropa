# Тропа

Мобильное приложение, которое мотивирует выходить на улицу каждый день: пройденные улицы
закрашиваются на карте, а каждое утро появляется квест, который ведёт в ещё не открытую часть города.

## Скачать

Готовый APK для Android — в разделе [Releases](../../releases). Установите файл на телефон
(Android попросит разрешить установку из неизвестного источника).

## Что умеет

- **Карта прогулок.** Улицы вокруг вас серые; пройденные во время прогулки закрашиваются.
  Процент открытых улиц района.
- **Парки — отдельные зоны.** Процент пройденных дорожек; при 80% парк «захвачен» 🏆.
- **Квест дня на выбор:** простой, средний, сложный (пройти улицу целиком) или в парке.
  Выбирать можно прямо на карте. Засчитывается фото с камеры, сделанное рядом с целью (проверка по GPS).
- **Погода.** Задания подстраиваются под дождь, снег, туман; в непогоду очки ×2;
  в грозу, гололёд и жару — только короткий квест рядом с домом; подсказка лучшего часа для прогулки.
- **Места рядом с целью** с переходом к отзывам в Яндекс Картах.
- **Профиль:** уровни, стрик дней, статистика за неделю, история прогулок и квестов.

## Технологии

- React Native + Expo (SDK 58), TypeScript.
- Карта: Яндекс Карты (JavaScript API в WebView); в Expo Go — запасная карта OpenStreetMap.
- Улицы, парки и места: данные OpenStreetMap из векторных тайлов [OpenFreeMap](https://openfreemap.org).
- Погода: [Open-Meteo](https://open-meteo.com), запасной источник — [MET Norway](https://api.met.no).
- Все данные пользователя хранятся только на телефоне.

## Запуск для разработки

```bash
cd mobile
npm install
cp .env.example .env.local   # и вставьте ключ «JavaScript API» с developer.tech.yandex.ru
npx expo start               # затем отсканируйте QR-код в Expo Go
```

Без ключа Яндекса в Expo Go показывается карта OpenStreetMap.

## Сборка APK

Облачная сборка: `npx eas-cli build -p android --profile preview`.
Локально (нужны JDK 17 и Android SDK): `npx expo prebuild --platform android`, затем в `mobile/android`
`gradlew assembleRelease`.
