# Тропа — мобильное приложение для прогулок

Отвечай на русском языке.

## Цель
Приложение, которое мотивирует выходить на улицу каждый день. Объединяет две идеи:
закрашивание карты пройденных улиц и ежедневный квест, с учётом погоды и сезонными ивентами.

## Основные функции
- **Закрашивание карты.** Пройденные улицы окрашиваются, остальные серые.
  Процент открытого района/города. Полностью пройденный район = «захвачен», значок на карте.
- **Квест дня.** Одно задание каждое утро, ведёт в неоткрытую (серую) часть карты.
  Засчитывается по фото с геолокацией.
- **Погода.** Квесты подстраиваются под погоду (дождь, снег, солнце); двойные очки за прогулку
  в плохую погоду; подсказка лучшего времени для прогулки; при шторме, гололёде или жаре —
  короткий квест рядом с домом.
- **Сезонные ивенты** (2–4 недели): осень «Золотой листопад», зима «Огни города»,
  весна «Пробуждение», лето «Белые ночи», плюс мини-ивенты на праздники.
  Награды: уникальные цвета карты и значки.
- **Прогресс.** Стрик с «заморозкой», уровни, значки, недельная статистика
  (км, новые улицы, часы на улице).

## Технологии (предварительно)
- Приложение: Flutter или React Native (ещё не выбрано — помоги выбрать).
- Карта: OpenStreetMap.
- Погода: Open-Meteo (бесплатно, без ключа).
- Геолокация: GPS телефона, сопоставление трека с улицами OSM.
